1.1 ¿Qué es Workflow?
» Esel denominativo técnico, en inglés, que se da a los flujos de trabajo.
» Es la automatización de los procesos institucionales, estos son comúnmente conocidos
como “trámites”.
» Es un medio que facilita el control de una amplía gama de procesos dentro de una
organización: datos, documentos, información o tareas, que son pasados de un individuo a
otro para interactuar entre ellos y alcanzar un objetivo en común. Dentro de un conjunto de
reglas,
1.2 ¿Qué significa Wayka?
WAYKA es una palabra que viene del Aímara y significa "reunirse comunitariamente para
atacar el trabajo eminentemente agrícola”.
1.3 Sistema Workflow Wayka
Es una herramienta para modelar procesos de negocio en forma electrónica y, permite diseñar,
ejecutar, supervisar y coordinar los flujos de trabajo en la organización, además, poder integrar
y potenciar todos los sistemas de una institución.

3. CONSIDERACIONES GENERALES DE LOS USUARIOS
Wayka es una plataforma que presenta los siguientes usuarios básicos e iniciales para la
administración del sistema.
Rol Detalle
Administrador de Sistema Es el usuario al que se le ha asignado las opciones
necesarias y suficientes para administrar el sistema, como
por ejemplo el registro de personas, usuarios, enlaces,
asignación de roles y menús, y sobre todo administración
de ABM de nuevas tablas.
Administrador de Wayka Es el usuario que tiene asignado opciones necesarias para
la administración de trámites/correspondencias, como por
ejemplo Anular un trámite, habilitar una correspondencia,
redireccionar procesos de un usuario a otro.
Diseñador de Wayka Es el usuario que tiene las opciones para el diseño de
nuevos procesos — trámites — entre las que podemos
mencionar, la creación áreas, procesos, actividades,
formularios, dominios, informes.
Ventanilla Única Es el usuario el cual puede hacer uso del diseño de un
proceso ya creado. Este usuario tiene acceso a su escritorio
virtual para crear e iniciar un proceso, ver sus
trámites/correspondencias pendientes, recepcionar
correspondencia, analizar y explotar datos de los procesos,
ver reportes, realizar búsquedas como bloquear y
desbloquear procesos observados.
Atención de | Es el usuario al que le llegan los trámites/correspondencias
trámites/correspondericias que debe atender. Asimismo tiene posibilidad de realizar
búsquedas y reportes del movimiento de los
trámites/correspondencias.

11.4 ADMINISTRAR LOCALIDADES
Se define una “localidad” a un municipio, a la llamada “zona urbanizada” de un pueblo o
Ciudad (sea que quede dentro de los límites de un municipio, sea que, por el contrario, rebase
esos límites), a una porción de esa “zona urbanizada” (especialmente cuando cada porción fue
alguna vez un trazado continuo separado y luego se consolidó con otros en uno solo), y, hasta
a un barrio, loteo, villa de emergencia, etc. dentro de una “zona urbanizada”.
Éste módulo fue realizado con la ayuda del sistema DibRap, éste le permite administrar las
diferentes localidades; se tiene la posibilidad de crear una nueva localidad además de
modificar o eliminar una ya existente.
